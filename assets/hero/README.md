# Homepage hero image

Place the supplied studio-room image in this folder as:

```text
studio-home.jpg
```

The homepage hero is already wired to use:

```css
assets/hero/studio-home.jpg
```

Recommended export:

- Aspect ratio: 2.39:1
- Width: 1800px or larger
- Format: `.jpg` or `.webp`
- Keep the monitor centered so the AR text overlays line up with the room.
